# GSB - Partie 1

Structure Vue préparée à partir du sujet GSB.

## Installation

```bash
npm install
npm run dev
```

## Structure

- `src/views/` : pages de l'application
- `src/components/` : composants réutilisables
- `src/services/` : communication avec l'API
- `src/stores/` : store Pinia
- `src/router/` : routes Vue
- `src/assets/` : ressources CSS/images
